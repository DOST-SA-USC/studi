Learn how to provide learning resources to Studi's repository.

## How to Contribute?

Submit your notes and files through our email `dostsausc.tech@gmail.com` by
filling up the email template below.

```
  Project Studi Notes Contribution
```

```
  Title:
  Intended Subject:
  Intended Program:
  Intended Year Level:
```

Afterwards, attach your files to the email.

### Sample Email

```
  Project Studi Notes Contribution
```

```
  Title: Binary Trees notes
  Intended Subject: Data Strucutres and Algorithms
  Intended Program: BS Computer Science
  Intended Year Level: 2

  [files attached below]
```
